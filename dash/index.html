What these numbers count
  • Installs come from the app's anonymous daily report (from 26.11.1002 on): one per Windows user on a PC, your own test copies included. Older versions don't report.
  • "New installs" are installs whose first report was their first ever launch. Until the app release after 26.11.1002, an older install that updated is counted as new too.
  • Website downloads count each person once a day: a one-way scramble of their IP address and browser with a secret that changes daily, so people can't be told apart across days and no IP address is kept. They start on 2026-11-10.
  • Downloads are GitHub's counts for each release's DesktopWiki.msi: the website's Download button, the app's updater and your own installs. They can't tell people apart.
  • Retention counts from each install's first report. "Back in their second week" is installs that reported again 7 to 13 days after it; "a month later", 28 to 34 days after. Only installs first seen long enough ago are counted. Installs that updated from a version without reports count from the day they first reported.
  • An install reports once a day, when it starts, so "up to date" and the "On it" columns use the version each install ran when it first started that day (or last restarted). "On it" means this release or a newer one, as the share of installs that reported that day. Columns are empty until that day has ended, and for days before reports began.
  • Installer size is the size of each release's DesktopWiki.msi on GitHub (1 MB = 1,048,576 bytes, as Windows shows it).
