Privacy

DesktopWiki is made by EmuKey LLC. This page says what the DesktopWiki app and this website collect. The full terms are in the license you accept when you install it.

Your wiki stays on your PC

Your wiki (pages, history, attachments, accounts, and the encrypted contents of password pages) is one file on the PC that runs DesktopWiki, with its backups in the folder you choose. DesktopWiki serves it only to the devices that connect to it on your network. It never sends your pages, attachments, accounts or any other content to EmuKey LLC or anyone else. Apart from the anonymous usage statistics below, it has no analytics, telemetry, advertising or crash reporting.

Update checks

DesktopWiki asks GitHub (api.github.com) whether a newer version is available when it starts and every few hours, and reads a small public file on GitHub (raw.githubusercontent.com) that says whether the beta is still running. It downloads an update only when an administrator chooses to install it, and installs only one signed by EmuKey LLC. GitHub receives your IP address and the app’s version number, and handles them under the GitHub Privacy Statement.

Usage statistics

To count how many people use DesktopWiki, once a day while it runs it sends EmuKey a short report with:

  • a random install ID, made on your PC the first time (it identifies that installation, not you);
  • the version of DesktopWiki;
  • the version of Windows;
  • whether it’s a new installation.

It never contains your wiki’s name, pages, files, accounts, names, email addresses or your computer’s name. We use the reports only as totals: how many installations there are, how many are in use, and which versions of DesktopWiki and Windows they run. The reports go to a counter we run on Cloudflare; your IP address reaches Cloudflare to deliver the report but isn’t stored with it. We keep reports for up to 400 days and never sell or share them.

To turn them off, an administrator clears Send anonymous usage statistics in Admin → Settings.

This website

desktopwiki.com counts its visits with Cloudflare Web Analytics, to learn how many people visit, which pages they read, where they came from and how many download the app. For each page view it records the page, the site that linked to it, the browser, operating system and type of device, and the country. It sets no cookies and stores nothing in your browser, and Cloudflare says it doesn’t fingerprint visitors or use IP addresses to follow them. We see only totals, never individual visitors. When you click Download, the link also passes through a download counter we run on Cloudflare, which counts each person once a day: it keeps a one-way scramble of your IP address and browser made with a secret that changes every day, so it can’t be turned back into your IP address or matched with another day, and your IP address itself isn’t stored. See the Cloudflare Privacy Policy. The site is hosted on GitHub Pages, which receives your IP address to serve it.
